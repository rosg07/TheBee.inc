Sobre Mí

Desarrollador Web (DAW)

¡Hola! Me llamo Roberto Sánchez y soy un estudiante de Desarrollo de Aplicaciones Web (DAW) de 25 años residente en Madrid. Mis dos pasiones son los coches y la tecnología, en especial, el software.

Soy un arquitecto de soluciones. Al igual que una abeja construye su colmena con precisión, yo construyo webs poniendo foco en la escalabilidad, el código limpio y una experiencia de usuario fluida. Soy meticuloso, curioso y siempre estoy buscando la siguiente tecnología para aprender.

Tengo experiencia con diferentes frameworks como Laravel, Symfony, Angular y Vue. A parte de manejar lenguajes de programacion como PHP, Python, Java y JavaScript. Tambien he utilizado herramientas como Git, Github y WordPress.

Este portfolio es mi carta de presentación: una demostración de que con paciencia, buenos ingredientes (HTML, CSS) y dedicación, se pueden crear productos con carácter propio.
